tutorials

Expanding our optimal transport survey, one piece at a time.

A hands-on companion to our survey "Recent Advances in Optimal Transport for Machine Learning" (IEEE TPAMI, 2024). The survey compresses a decade of work into a map of the field; this series walks the same ground slowly, with runnable code and worked intuition for each idea.

The code for every figure lives in the companion repository, examples-ot, as runnable notebooks. Each page below links to the notebooks it was built from.

The survey

This series expands the following paper. If the tutorials are useful in your work, please cite it.

2024

  1. TPAMI
    Recent Advances in Optimal Transport for Machine Learning
    Eduardo Fernandes Montesuma, Fred Maurice Ngolè Mboula, and Antoine Souloumiac
    IEEE Transactions on Pattern Analysis and Machine Intelligence, 2024
    Abs arXiv Bib PDF Code

    Optimal Transport (OT) is a probabilistic framework for comparing and manipulating probability distributions. We survey the contributions of OT to machine learning over 2012-2023 across supervised, unsupervised, transfer, and reinforcement learning, including computational OT, partial, unbalanced, Gromov, and Neural OT and their interplay with ML practice.
